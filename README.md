# 五行灵契 · Wuxing Spirit

**在现实环境中寻找伙伴，通过结契、照料与成长建立日常陪伴。**

一个东方幻想养成游戏的交互原型项目，正在探索摄像头实景与二维角色结合的轻量 AR 体验。

**阶段：原型探索。** 当前公开产品设计、核心实现片段和验证计划；未宣称完成原生空间 AR、健康数据接入或用户留存验证。

## 看什么

- [产品与玩法](docs/product.md)：寻灵 → 结契 → 照料 → 成长。
- [关键设计取舍](docs/decisions.md)：二维原型、权限与失败回退。
- [体验验证计划](docs/validation-plan.md)：哪些问题需要手机实测。
- [原型源码阅读](prototype/README.md)：现有页面与样式的文本快照。
- [地图与循环](design/game-loop.md)：已定义的内容与后续边界。

原项目有 React 网页原型，包含摄像头入口、附近点位、养成状态和本地保存逻辑。本仓库首版仅公开代码阅读快照，未包含视觉资源包和部署工程，因此不提供不完整的运行命令。

## 能力侧重

把世界观变成可操作的循环；用小原型检验角色陪伴感；明确视觉、定位和玩法数值的未验证部分。AI 辅助代码与素材探索，设计取舍和测试计划另行记录。
