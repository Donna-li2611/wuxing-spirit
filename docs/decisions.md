# 关键取舍

| 选择 | 当前收益 | 代价与再评估条件 |
| --- | --- | --- |
| 先用二维角色叠加实景 | 快速验证互动与陪伴感 | 扁平感可能影响体验；真机观察后决定是否制作 3D |
| 保留模拟寻灵 | 摄像头不可用时仍能探索玩法 | 必须清楚区分模拟与实时画面 |
| 本地保存养成状态 | 降低原型使用门槛 | 换设备或清理浏览器可能丢进度 |
| 先开放一个主要区域 | 聚焦循环验证 | 其他地图只能标为后续内容 |
| 健康行为只作奖励 | 尝试温和的日常参与 | 游戏阈值不代表医学标准 |

代码中的点位是围绕当前位置生成的游戏数据，不是真实世界地点推荐；定位精度、边界和安全交互仍需要专门验证。
