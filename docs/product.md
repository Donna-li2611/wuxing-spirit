# 产品与玩法

## 核心体验

让用户在短时间内完成一次发现与互动，再通过日常照料看到伙伴变化。首轮目标是验证“看得懂、愿意点、愿意再来”，还没有测量长期留存。

## 主循环

现实寻灵 → 开启场景 → 安抚结契 → 收入伙伴 → 投喂照料 → 成长进化 → 探索更多地图。

## 现有原型内容

- 五行初始伙伴与角色预览。
- 以苍梧森为主要开放区域，其他区域作为后续方向。
- 仙草、装备与伙伴库存。
- 日常任务与成长奖励。
- 摄像头实景叠加二维角色，无法开启时回到模拟场景。
- localStorage 保存部分养成状态。

## 健康行为探索

原型尝试把散步和手动睡眠记录与奖励连接。它们是游戏规则，不是健康建议或医疗评估；尚未接入手机健康数据库或手表。

本轮应观察玩家是否理解循环、是否感到互动自然，再决定是否投入完整 3D 与原生 AR。
