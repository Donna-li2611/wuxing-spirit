# 体验验证计划（待执行）

先招募少量愿意试用的观察对象，逐人记录设备、浏览器、是否首次使用和任务结果。计划不是已取得的用户反馈。

| 任务 | 观察内容 | 记录方式 |
| --- | --- | --- |
| 无讲解进入原型 | 是否理解先做什么 | 首次有效操作与困惑点 |
| 选择伙伴并寻灵 | 是否理解角色与场景关系 | 操作路径与错误入口 |
| 摄像头允许/拒绝 | 画面是否自然，回退是否可理解 | 两种条件分别记录 |
| 完成结契与投喂 | 是否知道操作产生了什么变化 | 玩家复述与状态变化 |
| 关闭后重新进入 | 预期哪些进度应保留 | 实际状态与预期对照 |

首轮不收集实际位置或健康记录到公开仓库。公开反馈应移除身份信息，仅保留必要的设备条件和观察结论。

相机、GPS、精确空间定位、后台运行分别验收；摄像头能打开不能证明完整 AR 已完成。
